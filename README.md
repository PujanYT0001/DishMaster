# DishMaster - Learn to Cook Delicious Dishes Easily

DishMaster is a premium, fully responsive recipe platform designed to help people cook food easily using written recipes and video tutorials.

## Features

- **Modern UI/UX**: Warm food-themed design with smooth animations.
- **Recipe Gallery**: Browse recipes by category, cuisine, and difficulty.
- **Interactive Details**: Step-by-step instructions with ingredient checklists.
- **Video Tutorials**: Embedded YouTube cooking guides for every dish.
- **User Features**: Save favorite recipes and manage your profile (localStorage-based).
- **Dark Mode**: Persistent dark theme for comfortable night-time cooking.
- **AI-Ready Search**: Search by dish name, ingredients, or cuisine.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom design system and animations.
- **JavaScript (ES6)**: Dynamic rendering and state management.
- **LocalStorage**: Persistent user data without a backend.

## How to Run

1. Clone this repository.
2. Open `index.html` in any modern web browser.
3. Enjoy cooking!
